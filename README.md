## Technical Workflow
The system initiates multiple TCP handshakes using the Keep-Alive protocol. Each thread injects randomized HTTP headers and browser metadata, forcing the target server to process unique, non-cached requests. This process rapidly consumes the servers worker pool and CPU cycles, demonstrating the limits of the target infrastructure.
